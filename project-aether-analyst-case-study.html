Background + Problem

What needed to be solved

Challenge

Analysts waste countless hours translating business questions into reproducible analyses. Existing AI chat tools generate suggestions but rarely produce verifiable, executable results. Unstructured documents (PDFs) are notoriously hard to query without context grounding, leading to hallucinations and wasted cycles.

Requirements

  • Automate code generation with built-in error correction.
  • Execute generated code safely in an isolated environment.
  • Ground document Q&A using RAG to avoid hallucinations.
  • Deliver reproducible, auditable results for stakeholders.
  • Work entirely offline with local LLMs (Ollama).
  • Professional, modern UI matching SaaS standards.
Technical Solution

Architecture and orchestration

Agentic Orchestration

LangGraph state machine implements a multi-step workflow: Plan → Code Gen → Execute → Self-Correct. If execution fails, the agent diagnoses the error, receives feedback, and regenerates corrected code automatically.

Sandbox Execution Engine

Custom Python sandbox isolates generated code with whitelisted imports only. Captures stdout, exceptions, figures, and returned results. Prevents arbitrary system calls while enabling full analytics capability.

Hybrid RAG Pipeline

Document loaders (PDF, Text, Markdown) feed into chunked embeddings via SentenceTransformers. FAISS vector store enables fast retrieval. Retrieved context is fed to LLM for grounded, hallucination-free answers.

Core Workflow

Dataset analysis example

User Input Flow

  • User uploads CSV/Excel/JSON dataset.
  • System extracts schema and summary statistics.
  • User asks a natural-language question about the data.

Agent Response Flow

  • LLM receives schema context + user prompt.
  • Generates fenced Python code snippet.
  • Sandbox executes; returns result/figure or error.
  • On error, agent receives feedback and retries.
  • Final result is synthesized into a narrative report.

Deployment & Usage

Quick start and production setup

Local Development

Clone repo → Create virtual env → Install deps → Run streamlit run main.py. Requires Ollama running locally with a model endpoint configured.

Production Setup

Docker container recommended. Mount volumes for SQLite persistence. Run Ollama on dedicated host or container. Expose app behind auth proxy for security. Optional: integrate with external LLM providers (Groq, OpenAI) instead of local Ollama.
